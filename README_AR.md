# Ahmed AutoBuy — النسخة التجريبية 0.1

هذا مشروع Android أولي لبناء APK عبر GitHub Actions (سحابيًا).

## ما الذي تفعله هذه النسخة؟
- تعرض واجهة أولية باسم Ahmed AutoBuy.
- تتضمن خدمة Accessibility تشخيصية لملاحظة أحداث واجهة تطبيق FP Card Selling.
- لا تنفذ مشتريات ولا تضغط أزرار الدفع ولا تقرأ أو تخزن الرقم السري أو أكواد البطاقات.

## البناء السحابي
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى المستودع على الفرع `main`.
3. افتح تبويب Actions وشغّل `Build Android APK`.
4. بعد نجاح البناء، نزّل Artifact باسم `AhmedAutoBuy-debug` وافتح ملف APK على هاتفك.

## تنبيه أمان
لا تضع الرقم السري الرباعي أو بيانات الحساب أو أكواد البطاقات في GitHub أو Telegram.
في مرحلة الاختبار، أبقِ إدخال الرقم السري يدويًا داخل التطبيق الأصلي. لا تمنح خدمة Accessibility صلاحيات إلا بعد فهمها ومراجعتها.
